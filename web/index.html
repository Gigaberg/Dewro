End-to-end harmonization

Collapse many inconsistent descriptions of the same item into one clean, structured record.

Datasets

Three public datasets back the pipeline — Flipkart supplies real Indian-context text; the others provide labeled references.

Duplicate detection

Group descriptions that refer to the same physical item by embedding similarity.

Attribute extraction

Pull structured fields (brand, material, dimension, standard, grade…) via spaCy NER + a domain regex layer.

Standardization

Rewrite a raw, inconsistent description into a clean, standardized form.

t5-small runs without fine-tuning (illustrative) — the rule/unit normalizer is the dependable output.
